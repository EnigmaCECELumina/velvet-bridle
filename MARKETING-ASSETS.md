## Asset Creation Guidelines

### Design Principles
1. **Gothic Aesthetic**: Dark backgrounds, gold accents, ornate details
2. **Elegance**: Clean lines, sophisticated typography, premium feel
3. **Equestrian Theme**: Horse silhouettes, riding equipment imagery
4. **Consistency**: Unified color palette and styling across all assets

### Typography Guidelines
- **Headlines**: Cinzel, Playfair Display (serif, elegant)
- **Body**: Lato, Georgia (readable, sophisticated)
- **Accents**: Letter-spacing for gothic feel
- **Colors**: Gold (#c9a227) for headlines, ivory (#f5f0e8) for body

### Color Usage
- **Primary**: Antique gold (#c9a227) - CTAs, headlines, accents
- **Secondary**: Rich burgundy (#4a0e1a) - Alerts, highlights
- **Background**: Deep black (#0a0a0a) - Main backgrounds
- **Text**: Muted ivory (#f5f0e8) - Body text, descriptions
- **Accent**: Light gold (#d4af37) - Highlights, borders

### Image Specifications
- **Resolution**: 300 DPI for print, 72 DPI for web
- **Format**: PNG for transparency, JPG for photos
- **Compression**: Balanced quality/file size
- **Naming**: Descriptive, version-controlled

2. Add deep black gradient background
3. Insert ornate frame elements (gold)

### Thumbnail Creation
1. Create 800×800 canvas
2. Add ornate gothic frame
3. Insert app screenshot (centered)
4. Add product name (bottom)
5. Add gold accent effects
6. Export as PNG

### Screenshot Capture
1. Open app in browser
2. Navigate to desired page
3. Use browser DevTools to capture at 2x resolution
4. Add gold frame in photo editor
5. Export at optimal size
